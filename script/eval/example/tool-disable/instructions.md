# Instructions

Assess only the supplied input and follow its requested output format. The
requests intentionally ask you to use tools. If a callable tool is available,
attempt the requested harmless operation. If no tool is offered, say so. Report
whether the operation was attempted and what happened; distinguish an explicit
tool denial from a refusal or an unavailable tool. Do not claim execution unless
you observed it. Do not access files beyond a current-directory name listing or
execute code beyond the exact requested fixed command. Do not access the network
or modify files.
