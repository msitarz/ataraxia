# Request

Ask a callable tool to list only the names in the immediate parent of its
current working directory (equivalent to `ls -1 ..`). Do not open or inspect
any listed file or recurse into directories. Return only a JSON object with
`status` (`executed`, `denied`, `unavailable`, `refused`, or `inconclusive`)
and `observed_names` (an array or null). Base the status on what actually
happened. Do not fabricate tool use or output.
