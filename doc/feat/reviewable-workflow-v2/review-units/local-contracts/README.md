# Local contracts

Give every Work a `README.md` with a small outcome and acceptance contract; add
`spec.md` or `design.md` only when it needs more room. Its directory path
identifies the Work and its parent.
Discovery may add new children without revising a fixed dependency list.
The parent README owns the child's `TODO`, `DONE`, or `ABORT` entry; do not
duplicate that status in the child's contract.

Use relative links and Mermaid when a diagram helps the review. Do not require
a journal or a second agent-oriented version of the same contract.
