## Preconditions and limits

The reported comparison used the integrated evidence revision and explicit
maintainer authorization for all three named model/effort conditions, the 18-run
cap, and fixed reviewer arrangement. It used the frozen fixture revisions,
prompts, guidance, tools, checks, fresh sessions, repetition count, and run
order without unplanned variation. Any further comparison requires a new
reviewed protocol and authorization.
The same owning parent dispatches directly to each leaf and reviews every
artifact; do not insert a Sol wrapper or transfer session context. The current
Luna-low default remains in force outside the authorized comparison.

The same owning parent independently reviews every initial artifact and
correction under the frozen rubric. Apply the rubric without condition labels
where practical; otherwise report what the parent knew about conditions and
prior results and the resulting unblinded-review confounds. Measure elapsed
time from dispatch through parent-reviewed artifact, parent review effort,
first-artifact acceptance, corrections, steering, check reuse or repetition,
and token/cost availability. Record unavailable token or cost values as
unknown. Include every run, deviation, stalled or incomplete case, and any
protocol-authorized replacement within the dispatch cap.

Stop if authorization, a fixture, a matched condition, fixed parent/reviewer
availability, or a required tool is missing. A stalled run, exceeded correction
cap, or protocol deviation is handled by the frozen rules; do not silently
substitute a run or claim a complete comparison from partial evidence. Report
condition and task-class results with the protocol's summary method and
limitations. Recommend an alternative only when it passes the predeclared
conservative decision rule and all correctness and preservation gates. Otherwise
retain the current default or report an inconclusive result. Any later policy
proposal uses the applicable WDR lifecycle and maintainer approval path.
