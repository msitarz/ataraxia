# Controlled comparison

Run the reviewed
[protocol and fixture at its frozen evidence commit](https://github.com/msitarz/ataraxia/blob/7e33df59e29160655e1145e50a03a1353acdf36d/doc/feat/reviewable-workflow-v2/trial-preparation/workflow-efficiency/single-agent-execution/protocol-and-fixture/README.md)
after it is integrated and the maintainer explicitly authorizes the nine
sessions and three control handoffs. Record evidence and a recommendation; make
no policy, PR, ready-state, or merge changes.

Run the three randomized pairs from the same fixture revision: three direct
executors, three orchestrators, and three delegated executors, all Luna-low.
Do not transfer context or artifacts. Missing authorization, fixture, or
matched conditions means stop; partial runs are not a comparison.

Apply local checks and the common independent rubric to every artifact. Report
per-run gate outcomes, timing, role effort, separate reviewer minutes,
checks/repeats, corrections, steering, preservation, tokens/cost, and protocol
deviations. Report paired outcomes, median, range, and limitations in the
existing trial record. Recommend change only if the declared rule passes;
otherwise retain the topology or report inconclusive. Do not generalize beyond
this task class.
