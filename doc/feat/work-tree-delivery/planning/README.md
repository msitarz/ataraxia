# Plan bounded leaves and pause the requested tree

Own planning/sizing/depth at [Work workflow](../../../workflow.md) and its
concise [orchestrator](../../../orchestrator.md) assessment/escalation route.
The orchestrator assesses each full leaf change against about five-minute
review; the definer iterates concrete contracts under independent review. A new
split or any needed maintainer decision pauses the entire requested tree, not
just the discovering branch. Reach safe stopping points, preserve in-flight
artifacts and evidence, stop new dispatch/implementation, and report the
decision/scope. Contract preparation needed for steering may continue under
owner review; expanded implementation waits for the concrete planning PR to
merge.

Replace the weak depth preference with a maximum five Work levels: count from
the topmost Work as level 1 through every descendant Work, including leaves.
A deeper proposal needs explicit maintainer approval; never silently renest
legacy trees. Count Work nodes, not helper/spec directories. Preserve model
selection and the pending role-policy Work rather than restating their defaults.
