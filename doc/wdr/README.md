# Workflow Decision Record index

This index lists numbered records about consequential delivery-workflow
choices. See the [WDR workflow](../wdr-workflow.md) for eligibility and
lifecycle, and the [shared decision record format](../decision-records.md) for
record syntax and changes.

## Accepted

The initial six records cover cross-Work choices about local Work contracts
and lifecycle, maintainer review capacity, delegated repository changes, and
delivery evidence. This first set does not record every inventory finding.
Narrower documentation, tool, test, and code-review practices remain with their
authoritative owners.
